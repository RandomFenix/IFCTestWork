# IFCTestwork

WPF-приложение .Net для просмотра IFC-моделей. Модель загружается из выбранного файла, отображается в 3D, элементы можно выбирать кликом по модели или в дереве иерархии, также есть возможность просмотра свойств

## Кратко о утилите

- Загрузка файлов `.ifc`
- 3D-просмотр: вращение, панорамирование, масштаб
- Дерево иерархии IFC: `IfcProject → IfcSite → IfcBuilding → IfcBuildingStorey → элементы`
- Двусторонний выбор:
  - выбор узла в дереве подсвечивает элемент (или всю группу элементов узла) на модели;
  - клик по элементу на модели выбирает соответствующий узел в дереве и раскрывает его родителей
- Таблица свойств
- Логирование в файл (NLog) и обработка ошибок загрузки

## Применяемые библиотеки

 - HelixToolkit.Wpf
 - Xbim.Ifc, Xbim.Ifc2x3, Xbim.Ifc4, Xbim.Essentials, Xbim.Geometry
 - NLog

## Требования

- Windows
- Visual Studio 2022
- .NET Framework 4.8
- Платформа сборки x64 ( для загрузки геометрического движка Xbim)

## Установка и сборка

1. Открыть решение в Visual Studio.
2. Установить NuGet-пакеты:
   - `HelixToolkit.Wpf`
   - `Xbim.Ifc`,
   - `Xbim.Ifc2x3`,
   - `Xbim.Ifc4`
   - `Xbim.Essentials`
   - `Xbim.Geometry`
   - `NLog`
3. Выбрать конфигурацию x64 (обязательно)
4. Убедиться, что у файла `NLog.config` в свойствах стоит "Копировать с поздней версией"
5. Собрать и запустить проект.

## Использование

1. Нажмите **Открыть файл** и выберите файл.
2. Дождитесь окончания загрузки. На больших моделях загрузка может занять какое-то время.
3. Выберите узел в дереве ifc или кликните по элементу на модели.

## Структура проекта

- MainWindow.xaml - главное окно приложения
- MainViewModel.cs - класс, отвечающий за логику загрузки ifc модели
- PropertyViewModel.cs - класс, отвечающий за наполнение свойств у элемента модели(если они есть)
- NodeItem.cs - класс сущности элемента дерева иерархии модели Ifc
- TableItem.cs - класс сущности таблицы свойств
- NLog.config - конфигурационный файл для настроек логирования

### Порядок работы

1. `IfcStore.Open` читает файл, `Xbim3DModelContext.CreateContext()` триангулирует геометрию.
2. Для каждого `ShapeInstance` создаётся `GeometryModel3D`. Для каждого продукта хранится список его мешей (`EntityLabel → меши`), для обратного поиска есть словарь `меш → продукт`.
3. Дерево строится из связей `IsDecomposedBy` (агрегация) и `ContainsElements` (содержание элементов в этаже или здании).
4. Свойство `Model3D` во ViewModel привязано к `ModelVisual3D.Content`, коллекция `Nodes` привязана к `TreeView`.
5. Выбор узла заменяет материал у его мешей на материал подсветки. Исходные материалы сохраняются и восстанавливаются при смене выбора.

## Логирование

Логи пишутся в:

```
%LocalAppData%\IFCTestWork\logs\log-YYYY-MM-DD.log
```

- Логируются время этапов загрузки,
- Необработанные исключения перехватываются в `App.xaml.cs` и записываются в лог.

Настройки уровня и формата лога меняются в `NLog.config`.
